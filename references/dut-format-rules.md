# 大连理工大学硕士学位论文格式规范（硬编码规则表）

本文件是**唯一事实来源**。改写/生成 `.docx` 时严格照此执行，不要凭记忆猜字号。

规则提炼自三份官方材料，冲突时以 **(1) 格式规范 docx** 为准：

1. `大连理工大学硕士学位论文格式规范.docx`（研究生院，2026-04-15 版）— **权威**
2. `DUTLatexSS/DUT-thesis-grd.cls`（LaTeX 模板，v1.2）— 仅作**旁证**，其左边距 2.7 cm、章标题 三号 与 docx 正文说明不一致，一律以 docx 为准
3. `MA Thesis.pdf` — 成品效果参照

> 下文所有数值均以 **磅(pt)** 为单位（python-docx 里就是 `Pt(n)`）。
> 中文 Word 的「行」单位：`1 行 ≈ 240 twips = 12 pt`（`w:afterLines="100"` ↔ `w:after="240"`）。

字体约定：

- **所有文字颜色一律为黑色（`w:color="000000"`）**。规范里「黑体」既是字体名
  （SimHei）也是颜色要求；官方模板的 Heading 样式**不写 `w:color`**，
  从而继承正文的自动黑。若基于 python-docx 内置模板生成，
  Heading 1/2/3 自带主题蓝（`365F91` / `4F81BD`），**必须显式清掉**，
  否则标题（含自动编号）在 Word 里是蓝的，打印出来更明显。
- 中文正文 → **宋体**
- 中文标题（各级标题、摘要题头、「关键词：」、表头）→ **黑体**
- 英文与数字 → **Times New Roman**
- 封面「硕士学位论文」→ **华文细黑**（`STXihei`），论文题目 → **华文细黑**
- 封面页脚「大连理工大学」→ **华文行楷**（`STXingkai`）

> 中文字体必须写 `w:eastAsia`（python-docx 的 `run.font.name` 只管西文，不管中文——这是最常见的失败点）。

## 四、封面（独立节，无页码）

- 页脚：「大连理工大学」（华文行楷 18 pt 居中）+「Dalian University of Technology」（Times New Roman 12 pt 居中）
- 「硕 士 学 位 论 文」：华文细黑 **24 pt** 加粗居中，字间加空格
- 论文中文题目：华文细黑 **22 pt** 加粗居中
- 论文英文题目：Times New Roman **16 pt** 加粗居中
- 字段块（作者姓名 / 学号 / 指导教师 / 学科、专业 / 答辩日期）：
  **隐藏边框的三列表格**：``标签 | 冒号 | 值``，三列各是**独立单元格**。
  官方开题报告首页即此结构（读它的 ``w:tblGrid``/``w:tcBorders`` 可确认）。
  - 表级边框全 ``none``，值单元格其余三边也全无。
    **三列必须分开成格**：把冒号并进标签列后，在 Word 里一加边框就会看到
    冒号和标签同格、分不开
  - **填写线 = 值单元格自己的下边框**（``w:bottom w:sz="4"``，0.5 磅）。
    线宽恒等于值列宽，**必然落在所填内容的下方**。
    **不要**让线单独占一列——那样线会跑到正文右侧、与值脱节
  - **标签列**（默认 2.7 cm）用**分散对齐**（``w:jc="distribute"``）。
    该列宽**决定字距**：2.7 cm → 字距紧凑（≈2 pt），接近正常书写；
    3.6 cm → 字距明显拉开（≈23 pt）。各标签天然宽度（15 pt）：
    ``学号`` 2 字 1.06 cm、``指导教师``/``答辩日期`` 4 字 2.12 cm、
    ``学科、专业`` 5 字 2.65 cm，故 2.7 cm 刚好略宽于最长标签，字距最小
  - **冒号列**（默认 0.6 cm，右对齐）：全角冒号约 0.53 cm
  - **值列**（默认 7.4 cm）居中。该列宽**决定填写线长度**
    （官方模板线长 ≈7.5 cm），同时须不小于最长值宽度，否则折行
    （15 pt 下「信息与通信工程」8 字 ≈ 4.23 cm）
  - **列宽必须写进 `w:tblGrid`** 并设 `w:tblLayout="fixed"`。
    python-docx 建的表默认等宽网格，只设 `cell.width` 无效，
    标签列被压窄后分散对齐会**逐字换行**（看起来像竖排）
  - 单元格下边距必须为 **0**，左右留白也要小（否则冒号列两边各多 0.1 cm）；
    段落用**固定行高 16 pt**、段后 6 pt。
    行高为「单倍」或设了 `w:trHeight` 下限时，Word 会撑高行框，
    把下边框推到下一行标签旁边，视觉上像串行（实测间隙会到 13 pt）

## 五、摘要

- 标题「摘　　要」：**小三 15 pt 黑体加粗居中**，1.5 倍行距，段前 0 行，**段后 1 行**
- 正文：**小四 12 pt 宋体**，首行缩进 2 汉字，**多倍行距 1.25**，段前段后 0 行，**取消网格对齐**（`w:snapToGrid val="0"`）
- **篇幅以一页为限**，文中不允许出现插图，重要表格可写入
- 正文后**空一行**，再列「关键词：」
- 「关键词：」题头 **小四黑体**（不可省略）；关键词 **小四宋体**，`；` 分隔，3–5 个，末尾不加标点
- 单位一律换算成国际标准计量单位制，数字用阿拉伯数码

## 六、英文摘要

- 标题「ABSTRACT」：同中文摘要题头规格，**Times New Roman 小三加粗居中**，段后 1 行
- 正文与中文摘要格式一致，字体改为 Times New Roman，首行缩进 2 字符，行距 1.25
- 「**Key Words：**」加粗，关键词 `;` 分隔，末尾不加标点

## 七、目录 / 图目录 / 表目录 / 主要符号表

- 标题「目　　录」：小三 15 pt 黑体加粗居中，段后 1 行
- 目录正文（`toc 1/2/3` 样式）：中文宋体、英文 Times New Roman，**小四**，1.25 倍行距
  - 一级条目左缩进 482 twips（≈0.85 cm），二级 480 twips，三级 840 twips
- 用**自动目录域** `TOC \o "1-3" \h \z \u`，并在 `settings.xml` 写 `w:updateFields val="true"`
- 「目录」标题自身 **不列入**目录 → 其段落 `w:outlineLvl val="9"`（正文级）
- 图目录 / 表目录同理：域分别用 `TOC \h \z \c "图"` / `TOC \h \z \c "表"`
- 目录编到**三级**（章 / 节 / 小节）

## 八、正文与各级标题

| 层级 | 示例 | 字体字号 | 对齐 | 行距 | 段前 | 段后 | outline |
|---|---|---|---|---|---|---|---|
| 章 | `1 绪论` | 黑体 **三号 16 pt** | **居左** | 1.5 倍 | 0 | 1 行（12 pt） | 0 |
| 节 | `1.1 研究背景` | 黑体 **四号 14 pt** | 居左 | 1.5 倍 | 0.5 行（6 pt） | 0 | 1 |
| 小节 | `1.1.1 试验方法` | 黑体 **小四 12 pt** | 居左 | 1.5 倍 | 0.5 行（6 pt） | 0 | 2 |
| 正文 | — | 宋体 **小四 12 pt** | 两端对齐 | **1.25 倍** | 0 | 0 | 9 |

- **每章另起一页**，章与章之间用分页符（`w:br w:type="page"`）分隔，**不要**用连续空行顶开
- 标号后空格：章标题「1」后空 **1 格**；节、小节标号后空 **1 格**（图示中为半角空格）
- 文科专业可将标题中的阿拉伯数字换成汉字
- 正文首行缩进用 `w:firstLineChars="200"`（**字符单位**），不要按磅硬算
- 正文必须设 `w:snapToGrid val="0"`（取消「对齐到网格」），否则行距会被网格拉偏
- 正文中的层次标题：`1 层次一标题` / `(1) 层次二标题` / `1) 层次三标题`（小四黑体或加粗，不进入目录）
- 每章应有引言性文字，「本章小结」收尾

## 九、图

- 位置：**居中**排列，图与下文之间留一空行
- 编号：**分章编号**，`图 1.1`、`图 3.2`（第 3 章第 2 个图）；附录中另编 `附录-图 A.1`
- 图名在**图下方**，图与图名必须在**同一页**，不得跨页
- 中文图题 + 英文图题**两行**，均用题注样式：
  - 中文：宋体 **五号 10.5 pt** 居中
  - 英文：Times New Roman 五号居中
- 编号与文字之间**留 1 个空格**，如 `图 1.1 系统结构图`
- 版式：嵌入型或上下型，**不得「浮于文字之上」**；单图尽量不超过一页，超限加续图
- 图片不要被压缩：Word 中勾选「文件 → 选项 → 高级 → 不压缩文件中的图像」
- 图中附注：阿拉伯数字 + 右半圆括号，如 `注1)`，写在图的**下方**
- 分图标 `(a) (b) (c)`

## 十、表

- 一律**三线表**：`表的上线 / 表头下线 / 表的下线`，**无竖线**
  - 上线、下线：**1.5 磅** → `w:sz="12"`（1/8 pt 单位，12 × 0.125 = 1.5 pt）
  - 表头下线：**1 磅** → `w:sz="8"`
  - 表中若需分组，组间可再加 0.5 磅细线（`w:sz="4"`）
  - 官方模板文件里的表头线实际为 0.5 磅（`w:sz="4"`），但**规范正文明确写 1 磅**，本技能按 1 磅执行
- 表题在**表上方**，中文表题 + 英文表题**两行**：
  - 中文：宋体 五号 居中，`表 3.1 国内外各返回式航天器热控设计情况`
  - 英文：Times New Roman 五号 居中，`Tab. 3.1 Design of thermal control systems ...`
- 表内文字全文统一：中文宋体、英文 Times New Roman，**五号 10.5 pt**，居中，**1.25 倍行距，无首行缩进**
- 表格与其上文的段落之间**留一行空格**
- 表格**用 Word 绘制，不要粘贴图片**；版式以一页为限，超限用续表
- 表中附注写在**表的下方**，格式同图注
- 编号同样分章：`表 2.3`

## 十一、公式

- 用 Word 自带**公式编辑器**（OMML）插入，不要用图片或纯文本凑
- 公式**居中**，编号在**行末**右对齐，格式 `(3.1)`，分章编号
- 实现：公式行设置**居中制表位**（版心中心）+ **右对齐制表位**（版心右边界），公式后 `Tab` 再写编号
- 公式行套「公式」样式：段前段后 **6 pt**（或半行），无首行缩进，行距单倍

## 十二、参考文献

- 标题「参 考 文 献」：**小三 15 pt 黑体居中**，1.5 倍行距，段前 0 行，**段后 1 行**
- 条目：**宋体五号 10.5 pt**（英文/数字 Times New Roman），**多倍行距 1.25**，段前段后 0 行，取消网格对齐
- 悬挂缩进 170 twips（约 0.3 cm），使第二行对齐序号后
- **在正文中用方括号 + 阿拉伯数字、右上角标**标注，按全文统一编号：`[1]`、`[2-4]`、`[6-10]`
- 条目**按正文首次引用顺序排列**，未被引用的条目删除
- 数量要求：**硕士不少于 50 篇**，其中英文文献 **≥ 60%**，近五年文献 **≥ 20%**
- 作者超过 3 位时**只列前三位**，其余用 `et al`（英文）或 `等`（中文）
- 文献类型标志（GB/T 7714-2005）：

## 十三、量和单位、规范表达

- 量和单位符合 **GB 3100~3102-93《量和单位》**，用**法定符号**，不用中文名称，不得使用已废弃单位（高斯、亩、克分子浓度 M、当量浓度 N 等）
- 外文**斜体**：变量符号、变动附标与函数、用字母表示的数与代表点线面体的字母、特征数符号（Re、Fo、Al）、视为常数的参数；**矢量、矩阵用黑体斜体**
- 外文**正体**：已定义函数（sin、exp、ln）、数学常数（e、π）、法定计量单位与词头量纲符号、数学符号、化学元素符号、机具仪器型号代号、硬度符号、不表示量的外文缩写、表示序号的拉丁字母、区别量符号的非量下角标
- 数字用法符合 **GB/T 15835-1995《出版物上数字用法的规定》**；标点符号符合 **GB/T 15834-1995《标点符号用法》**
- 名词术语前后一致；机关/团体/学校/研究机构名称首次出现写全称；外国人名可用原文不译
- **标量正体、向量黑体**
- 代码：Word 中直接排版代码格式复杂，建议把代码渲染成图片插入

## 十四、附录 / 致谢 / 攻读学位期间成果

- 「附录A  附录内容名称」：**小三黑体居中**，段后 1 行；附录小节用 Heading 1 重新排序（`附录 A` 下的 `1`、`2`…）
- 附录正文：小四宋体，首行缩进 2 字，1.25 倍行距，段前段后 0 行
- 附录中的图题/表题：`附录-图 2.1 …` / `App. Fig. 2.1 …`、`附录-表 2.1 …` / `App. Tab. 2.1 …`
- 附录可省略（无内容则删掉该页）
- 「攻读硕士学位期间科研项目及科研成果」：小三黑体居中，段后 1 行；正文小四宋体
  - 依次列：已发表论文 / 待发表论文 / 发明专利 / 获得奖励 / 参与科研项目
  - 每条注明**与学位论文相关章节**，如 `(本学位论文第三章)`
- 「致　　谢」：小三黑体居中，段后 1 行；正文小四宋体；**不可省略**，不得书写与论文工作无关的人和事（可写家人）

## 十五、页眉页脚与页码

| 分节 | 内容 | 页码 |
|---|---|---|
| 封面 | 无页眉，页脚为「大连理工大学 / Dalian University of Technology」 | 无 |
| 独创声明 / 授权书 / 答辩委员会 | 无页码（不编入） | 无 |
| 摘要 / ABSTRACT / 目录 / 图目录 / 表目录 / 主要符号表 | 页眉「大连理工大学硕士学位论文」 | **罗马数字** I、II、III…（`upperRoman`，start=1） |
| 正文（绪论起）～ 致谢 | 同上页眉 | **阿拉伯数字从 1 起**（`decimal`，start=1） |

- 必须在 `settings.xml` 写 `w:evenAndOddHeaders`（**奇偶页页眉不同**）
  - **奇数页页眉**：`大连理工大学硕士学位论文` — 宋体，**五号 10.5 pt**，居中
  - **偶数页页眉**：**论文中文题目** — 宋体，五号，居中
- 页脚：页码在**底部居中**，Times New Roman（正文可用宋体），**小五 9 pt**
  - 常规页：`- 7 -`（短横 + 空格 + PAGE 域 + 空格 + 短横）
  - **每章首页**页脚特殊：居中显示「大连理工大学硕士学位论文」（LaTeX 模板行为）；Word 版可直接沿用统一 `- n -`
- 页码域用 `PAGE`；分节页码格式由该节 `w:pgNumType` 的 `w:fmt` / `w:start` 控制
- 页码从**绪论首页**算作第 1 页；前置部分（摘要、目录等）单独用罗马数字编排
- 奇数/偶数页眉靠 `w:evenAndOddHeaders` + `w:headerReference w:type="even"` 实现（python-docx 用 `section.even_page_header`）

## 十六、打印顺序（供排版检查参考）
